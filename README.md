# 🌫️ AI Air Doctor

**結合 IoT 空品數據與環境醫學知識的個人化空氣品質健康代理人**

> AI Agent + Domain Knowledge + Data Analytics + Real-World Application

## 專題簡介
AI Air Doctor 是一個 Domain AI Agent。使用者只要用自然語言提問,例如「我有氣喘,明天早上去公園跑步可以嗎?」,系統就會:
1. 取得即時空品(環境部、民生公共物聯網)與氣象資料
2. 預測未來 24 小時 PM2.5
3. 依照使用者的健康狀況計算個人風險
4. 檢索 WHO 與 AQI 環境醫學知識
5. 提供**有依據**的個人化建議
